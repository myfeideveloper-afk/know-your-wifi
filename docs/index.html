Start the scanner on this computer

Browsers can’t see other devices on your network by themselves. A small scanner runs on your computer, and this page shows what it finds. You need Node.js 18+. 

git clone https://github.com/myfeideveloper-afk/know-your-wifi.git
cd know-your-wifi/agent
npm start

When it says “agent running”, this page connects automatically. Chrome may ask to allow access to local network devices. Click Allow. On Safari, open http://127.0.0.1:7878 instead.

Scanner on a different port?

    Private MAC means the device (usually a phone, tablet or laptop) uses a randomized address, so its maker can’t be identified. Click a device name to give it a nickname. Nicknames stay in this browser.
